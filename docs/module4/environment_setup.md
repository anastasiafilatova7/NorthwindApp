# Настройка среды разработки

## 1. Выбранный стек

- **Язык программирования:** Python 3.12
- **Интерфейс:** Tkinter (встроенная библиотека Python)
- **СУБД:** PostgreSQL 16
- **Библиотека для работы с БД:** psycopg2-binary
- **IDE:** IDLE (встроенная среда разработки Python)
- **Контроль версий:** Git + GitHub

## 2. Настройка IDE

Для комфортной работы были выполнены следующие настройки:
- Используется встроенная среда IDLE, которая не требует установки дополнительных плагинов и поддерживает базовый запуск и отладку скриптов.
- Настроен единый стиль кода (отступы 4 пробела) с помощью файла `.editorconfig` для всего проекта.

## 3. Контроль качества кода

- **Форматтер:** `black` — для единообразного форматирования кода.
- **Линтер:** `flake8` / `pylint` — для поиска синтаксических и стилистических ошибок.
- **Git-хуки:** настроены через `pre-commit` (файл `.pre-commit-config.yaml`). При попытке коммита автоматически проверяется код, и коммит блокируется, если линтер находит ошибки.
