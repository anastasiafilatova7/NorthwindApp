# Нефункциональные требования (NFR)

## 1. Производительность

| ID | Требование | Метрика |
|---|---|---|
| NFR-1.1 | Время загрузки списка продуктов | ≤ 2 секунд при 1000 записей |
| NFR-1.2 | Время отклика на CRUD-операцию | ≤ 1 секунды |
| NFR-1.3 | Время формирования отчёта начальника | ≤ 3 секунд |
| NFR-1.4 | Подключение к БД | ≤ 1 секунды |

## 2. Доступность

| ID | Требование | Метрика |
|---|---|---|
| NFR-2.1 | Доступность системы в рабочее время | ≥ 99% |
| NFR-2.2 | Восстановление после сбоя | ≤ 30 минут |
| NFR-2.3 | Резервное копирование БД | ежедневно |

## 3. Безопасность

| ID | Требование | Метрика |
|---|---|---|
| NFR-3.1 | Авторизация по логину и паролю | обязательна для всех ролей |
| NFR-3.2 | Разграничение прав доступа | каждая роль видит только свои модули |
| NFR-3.3 | Хранение паролей | не в открытом виде (перспектива — хеширование) |
| NFR-3.4 | Параметризованные SQL-запросы | защита от SQL-инъекций (используется %s) |

## 4. Масштабируемость

| ID | Требование | Метрика |
|---|---|---|
| NFR-4.1 | Увеличение числа клиентов | до 10 000 записей без потери скорости |
| NFR-4.2 | Увеличение числа заказов | до 100 000 записей |
| NFR-4.3 | Число одновременных пользователей | до 10 |

## 5. Удобство использования

| ID | Требование | Метрика |
|---|---|---|
| NFR-5.1 | Интерфейс на русском языке | все подписи и сообщения |
| NFR-5.2 | Понятность действий | ≤ 15 минут на обучение нового сотрудника |
| NFR-5.3 | Обратная связь | сообщения об успехе/ошибке после каждой операции |
| NFR-5.4 | Подтверждение опасных действий | диалог при удалении |

## 6. Совместимость

| ID | Требование | Метрика |
|---|---|---|
| NFR-6.1 | ОС | Windows 10/11 |
| NFR-6.2 | Python | 3.12+ |
| NFR-6.3 | PostgreSQL | 16+ |
| NFR-6.4 | Разрешение экрана | 1024×768 и выше |
