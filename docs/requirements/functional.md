# Функциональные требования (FR)

## FR-1. Авторизация и разграничение прав

| ID | Требование |
|---|---|
| FR-1.1 | Система должна запрашивать логин и пароль при запуске |
| FR-1.2 | Система должна проверять данные через `auth.py` |
| FR-1.3 | При неверных данных система должна выводить сообщение об ошибке |
| FR-1.4 | При верных данных система должна открывать окно, соответствующее роли |
| FR-1.5 | Система должна поддерживать 4 роли: warehouse, personnel, manager, boss |

## FR-2. Модуль «Склад» (warehouse)

| ID | Требование |
|---|---|
| FR-2.1 | Просмотр списка продуктов (ID, название, цена, остаток) |
| FR-2.2 | Добавление нового продукта |
| FR-2.3 | Редактирование цены и количества продукта |
| FR-2.4 | Удаление продукта |
| FR-2.5 | Просмотр списка категорий (ID, название, описание) |
| FR-2.6 | Добавление новой категории |
| FR-2.7 | Удаление категории (с обнулением привязки у продуктов) |

## FR-3. Модуль «Кадры» (personnel)

| ID | Требование |
|---|---|
| FR-3.1 | Просмотр списка сотрудников (ID, ФИО, должность, город, страна) |
| FR-3.2 | Добавление нового сотрудника |
| FR-3.3 | Редактирование данных сотрудника |
| FR-3.4 | Удаление сотрудника (с обнулением привязки в orders) |

## FR-4. Модуль «Менеджер» (manager)

| ID | Требование |
|---|---|
| FR-4.1 | Просмотр последних 100 заказов |
| FR-4.2 | Создание нового заказа с проверкой существования клиента |
| FR-4.3 | Редактирование страны доставки заказа |
| FR-4.4 | Удаление заказа вместе с его деталями |
| FR-4.5 | Просмотр списка клиентов |
| FR-4.6 | Добавление нового клиента (ID не более 5 символов) |
| FR-4.7 | Редактирование данных клиента |
| FR-4.8 | Удаление клиента вместе с его заказами |

## FR-5. Модуль «Начальник» (boss)

| ID | Требование |
|---|---|
| FR-5.1 | Отчёт по клиентам: компания и количество заказов |
| FR-5.2 | Отчёт по сотрудникам: ФИО и количество заказов |
| FR-5.3 | Отчёт по категориям: количество продуктов и средняя цена |

## FR-6. Общие требования

| ID | Требование |
|---|---|
| FR-6.1 | Все операции с БД выполняются через `psycopg2` |
| FR-6.2 | Параметры подключения хранятся в `db_config.py` |
| FR-6.3 | Ошибки выводятся через `messagebox.showerror` |
| FR-6.4 | Успешные действия подтверждаются через `messagebox.showinfo` |
