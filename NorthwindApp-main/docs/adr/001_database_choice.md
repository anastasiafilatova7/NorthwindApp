# ADR 001: Выбор СУБД — PostgreSQL

## Статус
Принято.

## Контекст
Проект NorthwindApp — оконное приложение на Python (Tkinter) для работы с БД Northwind. Необходимо выбрать СУБД, которая:
- Бесплатна и открыта
- Поддерживает ACID-транзакции и целостность данных
- Хорошо интегрируется с Python
- Подходит для многопользовательского режима (4 роли с разными правами)

## Рассмотренные варианты
1. **PostgreSQL** — объектно-реляционная СУБД, открытая, соответствует стандартам SQL
2. **MySQL** — популярная, но менее строгая по стандартам
3. **SQLite** — встроенная, но не подходит для многопользовательского режима

## Решение
Выбрана **PostgreSQL 16**.

## Обоснование
- Полностью бесплатна и открыта (лицензия PostgreSQL License)
- Поддерживает ACID-транзакции
- Богатый набор типов данных (включая `serial`, `bytea`, `numeric`)
- Отличная интеграция с Python через драйвер `psycopg2-binary`
- Уже используется в учебной БД Northwind
- Поддерживает разграничение прав доступа через `GRANT` / `REVOKE` — важно для 4 ролей (warehouse, personnel, manager, boss)

## Последствия
**Положительные:**
- Надёжное хранение данных
- Возможность разграничения прав доступа (4 роли)
- Стандартный SQL, легко переносить между СУБД
- Активное сообщество и документация

**Отрицательные:**
- Требуется установка и настройка сервера PostgreSQL
- Пользователям нужно устанавливать драйвер `psycopg2-binary`
- Немного выше порог входа для новичков по сравнению с SQLite
